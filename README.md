# sidco_plus
Matlab code used for publication and complimet.ca/sidco+ site
Provided files were used for all figures shown in the paper and provide methodology and code used for Monte Carlo simulation, calculation of all different types of correlations, p-values and CI (specifics provided in the associated publication). All code is written in Matlab and provided as is (with substantial comments and information). Names of files correspond to the figures in the manuscript. 
Code used for SIDCO+ site are also provided in  full. Site uses compiled version of this code that is called through RShiny app.R, also provided on the site. To implement this application locally user can either run it directly from Matlab of use compiled version (with R2026 Run Time library for Windows or Linux).
Code for all figures in the manuscript are provided in manuscript branch;
Code for sidco+ is provided in application branch.
